# Qassim TV Launcher v3

واجهة جديدة بخلفية جبال وبحيرة عند الغروب مرسومة داخل التطبيق دون الحاجة إلى اتصال بالإنترنت، مع أيقونات التطبيقات الحقيقية، خمس بطاقات في الصف، تحديد واضح بالريموت، والمفضلة بالضغط المطول. زر Qassim TV Care يفتح مركز الصيانة الموجود بالمشروع الأصلي.

## البناء
ارفع محتويات هذا المجلد إلى جذر مستودع GitHub (وليس المجلد الحاوي نفسه). افتح Actions وشغّل Build Qassim TV Launcher APK. حمّل artifact بعد نجاح البناء.

## ملاحظات
لم يتم تنفيذ بناء Android فعلي في هذه البيئة؛ يلزم اختبار APK على التلفزيون. تعتمد قائمة التطبيقات على إمكان رؤية التطبيقات المتاحة بحسب إصدار Android وسياسات الجهاز. بعض صفحات الصيانة قد لا تتوفر في جميع أجهزة التلفزيون.
