# SMART TV Launcher v3.2 — Offline AI Doctor

- افتح TV Care ثم AI Doctor لبدء التشخيص المحلي.
- التشخيص مبني على قواعد تفسيرية (rule-based)، وليس نموذج LLM. لا يحتاج إلى إنترنت أو API key.
- يعرض حالة RAM والتخزين واتصال الشبكة المحلي وإصدار Android ومدة التشغيل، مع توصيات ومشاركة التقرير.
- جميع الفحوص للقراءة فقط. لا توجد أوامر حذف، تنظيف تلقائي، أو إعادة تشغيل.
- لا يطلب صلاحيات Root أو QUERY_ALL_PACKAGES أو صلاحيات إدارة الجهاز.
- أُبقيت صلاحية INTERNET الموجودة في المشروع السابق من أجل لوحة التحكم المحلية؛ AI Doctor لا يستخدمها.
- ملاحظة أمنية: لوحة التحكم المحلية في المشروع السابق يجب حصرها بالشبكة الموثوقة ومراجعة آلية التوثيق قبل تعريضها للإنترنت.
- البناء: ارفع محتويات ZIP إلى جذر GitHub ثم شغّل Actions > Build SMART TV Launcher APK.
- لم يتم تنفيذ بناء APK فعلي في هذه البيئة؛ اختبره على تلفزيونك بعد البناء.
