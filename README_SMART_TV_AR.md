# SMART TV Launcher 3.1

- الاسم المعروض: SMART TV.
- تاريخ ميلادي وهجري (التقويم الهجري المحسوب قد يختلف عن أم القرى، خاصة على الأجهزة القديمة).
- التحكم من متصفح الجوال أو الكمبيوتر: افتح العنوان الظاهر على التلفزيون، ثم أدخل رمز PIN المعروض.
- الهاتف والتلفزيون على نفس شبكة Wi-Fi/LAN. المنفذ 8765.
- إعادة ترتيب التطبيقات بالأعلى/الأسفل، تشغيل التطبيقات، المفضلة، وطلب إلغاء التثبيت.
- يتطلب إلغاء التثبيت موافقة على التلفزيون ولا يمكن تجاوز قيود Android.
- رمز PIN يتغير مع إعادة تشغيل التطبيق؛ لا تعرض المنفذ للإنترنت العام أو شبكات غير موثوقة.
- التحكم لا يتضمن بث الشاشة أو التحكم الكامل بنظام Android أو تحريك مؤشر الريموت؛ هذه وظائف تحتاج صلاحيات أو خدمة إضافية.
- بعض أجهزة Android TV قد لا تعرض كل التطبيقات بسبب قيود النظام.
- افتح GitHub Actions لبناء APK؛ لم يتم اختبار APK فعليًا هنا.
