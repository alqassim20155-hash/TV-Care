# Qassim TV Launcher v2.1 + Qassim TV Care

مشروع Android Java لتلفزيونات Android TV.

## الجديد
- شاشة Qassim TV Care متكاملة مع القائمة الرئيسية.
- بطاقات حالة الشبكة والتخزين والذاكرة والبطارية (إن كانت مدعومة).
- معلومات الجهاز وإصدار Android ووقت التشغيل.
- أزرار إعدادات النظام وWi-Fi والتطبيقات والتخزين وإمكانية الوصول.
- الوصول إلى إعدادات التطبيق لمسح الذاكرة المؤقتة يدويًا.
- التنقل بالريموت، وإظهار التحديد عند التركيز.

## بناء APK
ارفع **محتويات** هذا المجلد إلى جذر مستودع GitHub، ثم Actions > Build Qassim TV Launcher APK > Run workflow. حمّل APK من Artifacts.

## تنبيه
التطبيق لا يمسح بيانات التطبيقات الأخرى تلقائيًا ولا يمتلك صلاحيات النظام لإعادة التشغيل أو إغلاق التطبيقات بالقوة. حالة الشبكة لا تقيس سرعة الإنترنت الفعلية. لم يتم تنفيذ بناء APK محليًا.
